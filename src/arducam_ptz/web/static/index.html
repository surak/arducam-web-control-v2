How to use this

Move the camera with the pad: drag the knob, or press the arrow keys after clicking the pad. The further you drag, the faster it moves.

Focus with the slider or the near/far buttons, or press AF to run an autofocus sweep. With "tap the image" enabled, a tap sets the area to focus on - the marker shows where.

Photos with the shutter button, then g for the grid. Tap a photo there to see it full size; download and delete are in that view, and the left/right arrows step through it.

Shortcuts: ←→↑↓ move, -/+ focus, f autofocus, space capture, c centre, g photos, ? this panel, E emergency stop (cuts servo power).

The image is a live MJPEG stream from the server. Everything you see here talks to the same HTTP API a script or another app would use - see /docs for the OpenAPI UI by hand, or /api/version for a version check.
